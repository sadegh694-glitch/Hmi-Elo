# HMI آموزشی راه‌اندازی الکترولایزر

یک رابط آموزشی فارسی و تعاملی برای توالی راه‌اندازی تک‌الکترولایزر ممبرانی `41EL08101A` با ۱۶۳ المان.

![آیکون HMI](assets/electrolyzer-hmi-icon.png)

فایل اصلی: `electrolyzer-console.html`

## قابلیت‌ها

- ۹ گام با تأیید چک‌لیست و اعتبارسنجی مقادیر آموزشی، بدون پرش آزاد
- شماتیک مفهومی متحرک، حالت روز/شب و نمای تطبیق با سند
- جدول‌های ۶-۵ و ۶-۶، یک منبع محاسبات دبی، درصد بار، چگالی تقریبی و حداقل زمان رمپ
- سناریوی ممبران نو با رمپ معادل ۰٫۱ kA/min و سقف ۱۰ kA در ۲۴ ساعت اول
- آزمون‌های مشروط برای سابقهٔ F-STATE، توقف طولانی و توقف استثنایی
- دامنهٔ بازبینی: تک‌الکترولایزر در سالنِ در حال تولید، صفحات ۴۱۶–۴۲۶، ۴۴۰–۴۴۲ و ۴۷۵–۴۷۶ سند `8408205-CB-PR-MNL-0102 Rev.02`
- ثبت موقت تأییدها؛ با بارگذاری مجدد، همهٔ تأییدها پاک می‌شوند

جدول‌ها با تصویر اصل سند تطبیق داده شده‌اند. دبی کاتولیت از آستانهٔ ۴ kA برابر ۴۱٫۷ m³/h است. اختلاف ۱۴٫۹ در متن و ۱۴٫۸۶ در جدول پنهان نشده است. محاسبات، وضعیت‌های هدف و تأییدهای دستی جایگزین اندازه‌گیری یا مجوز واقعی نیستند؛ رویهٔ کل سالن و خاموشی در این مدل اجرا نمی‌شوند.

## بررسی منطق

`node assets/verify-app.cjs`

این تست‌ها بدون مرورگر، محاسبات، مرزها، قفل مراحل و سناریوها را بررسی می‌کنند؛ آزمون بصری نیستند.

## اجرا

این پروژه وابستگی و فرایند build ندارد. فایل `electrolyzer-console.html` را با یک مرورگر باز کنید.

## انتشار با GitHub Pages

1. مخزن را به GitHub ارسال کنید.
2. از بخش **Settings → Pages**، گزینهٔ **Deploy from a branch** را انتخاب کنید.
3. شاخهٔ `main` و پوشهٔ `/(root)` را برای انتشار برگزینید.
4. پس از انتشار، GitHub Pages همین فایل `electrolyzer-console.html` را به‌عنوان صفحهٔ اصلی نمایش می‌دهد.
5. برای آیکون آیفون، پوشهٔ `assets` و فایل `manifest.webmanifest` را کنار فایل‌های HTML منتشر کنید. در Safari صفحهٔ منتشرشده را باز کنید و از منوی اشتراک‌گذاری «Add to Home Screen» را بزنید؛ برنامه را از آیکون جدید اجرا کنید. نوار نشانی پایین صفحه بخشی از Safari است و فقط هنگام اجرای نسخهٔ نصب‌شده روی صفحهٔ اصلی نمایش داده نمی‌شود.

## یادداشت ایمنی

این HMI صرفاً آموزشی و تصمیم‌یار است و هیچ فرمانی به تجهیزات، FCS، SIS، رکتیفایر یا ولوها ارسال نمی‌کند. عملیات واقعی فقط باید بر پایهٔ رویه‌های مصوب سایت و تأیید اپراتور مجاز انجام شود.
